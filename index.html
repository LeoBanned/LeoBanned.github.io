    05 /ПОЛЕЗНО ЗНАТЬ

    Перед первым
    запуском.

    Что нужно для запуска?+

    Windows 10 или 11, 64-битная система и WebView2 Runtime. Инструкции по сборке из исходников доступны на GitHub. Отдельные операции требуют прав администратора или перезапуска Steam.

    Это приложение с открытым кодом?+

    Да. Код проекта опубликован на GitHub под GPL-3.0-only. Встроенные сторонние компоненты распространяются по своим лицензиям.

    Локальное облако работает со всеми играми?+

    Оно предназначено для игр, подключённых через Lua с манифестами. Вы выбираете папку хранения и можете отключить режим без удаления сохранений. Поддержка зависит от игры и версии Steam; отдельная резервная копия прогресса остаётся полезной.

    Как обновляется программа?+

    Новая версия скачивается внутри приложения с отображением прогресса. После проверки программа заменяет EXE по прежнему пути и перезапускается. Обновление можно отменить до замены файла или отложить напоминание на пять запусков.
